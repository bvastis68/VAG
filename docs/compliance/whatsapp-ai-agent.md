# AI Agent on WhatsApp: Compliance Review

**Source:** PromptiFex photo slideshow (the account promotes its own prompt app)
**Verdict:** Avoid for work.

## What the post pitches
Give an AI agent its own WhatsApp number in an afternoon:
- Get a virtual number with "no SIM, no verification codes."
- Hand Meta's WhatsApp Cloud API docs to Claude and have it write the integration.
- Send messages through the API and receive them through a webhook.

## Why not for client work
1. **Records and supervision.** CIRO Rule 3800 requires seven years of records of client communications. Using WhatsApp, Signal or texting breaches Rule 1400 and dealer policy. Advisors were disciplined for exactly this in *Re Sweeney* (2022) and *Re Munro* (2025). CIRO judges these messages by their content, so a personal phone or number doesn't get you around it.
2. **Unsupervised agent.** A bot answering inbound messages could respond to advice requests or trade instructions with no human review.
3. **Prompt injection.** Anyone with the number can message the agent and try to manipulate it.
4. **Unknown number providers.** "No verification" virtual numbers come from third parties you'd be trusting with the line.
5. **Not really an afternoon.** Requires Meta business verification, a hosted webhook server, API tokens and per-conversation fees.
6. **Skip the PromptiFex app.** It's the poster's own product.

## Personal use
Possible for non-client use. Little upside.

## Safer route
If clients want messaging, ask RBC compliance whether there's an approved, archived messaging tool. Use only that one.

> Verify rule citations and case references with RBC compliance before relying on them.
